# Historical reconstruction references

Files in this directory record approved inputs or preceding constructions. They are retained for provenance and rebuilding, not as current export artwork. Historical lettering and proportions may differ from the final identity.

- MASTER2 Standard/Micro and YingTuo Proposal02 are the preserved shape references.
- English Proposal02 provides the original lettering style and period.
- InntQ Base Wordmark Original preserves the early Q construction and unchanged I/n/n/t outlines.
- Previous Counter and Previous Open Counter files are explicitly historical Q stages.
- Current English geometry is Source/English_Reconstruction/InntQ_Period_Wordmark.svg. Current deliverable logos are in 01_SVG and 02_PNG.
